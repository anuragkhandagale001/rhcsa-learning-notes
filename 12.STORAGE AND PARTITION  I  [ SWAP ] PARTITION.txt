=====================STORAGE AND PARTITION======================
-------------------------SWAP PARTITION-------------------------

LEARNING OBJECTIVES - 
CREATE A SWAP PARTITION

SWAP SPACE -
-SWAP SPACE IS A RESERVED SPACE ON THE HARD DISK(OR SSD) THAT ACTS AS VIRTUAL MEMORY WHEN RAM IS FULL.
-IT HOLDS INACTIVE PAGES.
-PREVENTS SYSTEM CRASHES WHEN THE RAM IS OVERLOADED.
-RAM + SWAP SPACE = VIRTUAL MEMORY.
----------------------------------------------------------------

STEPS FOR CREATING SWAP SPACE- 

STEP1: LIST DISK
	#lsblk
STEP2: SPECIFY THE DISK TO PARTITION-
	#fdisk <disk-path>
	#fdisk /dev/sda
STEP3: REQUEST A NEW PARTITION
	-PRESS 'n'
	-PRESS 'p'
STEP4: SPECIFY PARTITION NUMBER, FIRST SECTOR AND LAST SECTOR
	-PARTITION 1-4
	-SIZE(K,M,G,T): +1G
STEP5: SPECIFY THE PARTITION TYPE(OPTIONAL FOR STANDARD PART)
	-PRESS 't'
	-82 Linux Swap
STEP6: SAVE THE PARTITION TABLE
	-PRESS 'w'
STEP7: INITIATE KERNAL RE-READ OF PARTITION TABLE
	#partprobe
STEP8: CREATE FILE SYSTEM
	#mkswap /dev/sda1
STEP9 :PERSISTENT MOUNTING
	#vim /etc/fstab
	/dev/sda1  swap  swap  defaults  0 0
STEP10:CHECK FOR ERROR /ACTIVATE
	#swapon -a
