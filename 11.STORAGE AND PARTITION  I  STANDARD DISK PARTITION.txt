----------------------------------------------------------------

STEPS FOR CREATING PARTITION- 

STEP1: LIST DISK
	#lsblk
STEP2: SPECIFY THE DISK TO PARTITION-
	#fdisk <disk-path>
	#fdisk /dev/sda
STEP3: REQUEST A NEW PARTITION
	-PRESS 'n'
	-PRESS 'p'
STEP4: SPECIFY PARTITION NUMBER, FIRST SECTOR AND LAST SECTOR
	-PARTITION 1-4
	-SIZE(K,M,G,T): +1G
STEP5: SPECIFY THE PARTITION TYPE(OPTIONAL FOR STANDARD PART)
	-PRESS 't'
	-DEFAULT: Linux
STEP6: SAVE THE PARTITION TABLE
	-PRESS 'w'
STEP7: INITIATE KERNAL RE-READ OF PARTITION TABLE
	#partprobe
STEP8: CREATE FILE SYSTEM
	#mkfs.xfs /dev/sda
STEP9: MOUNT THE FILE SYSTEM
	#mkdir /PART1
	#mount /dev/sda /PART1
STEP10:PERSISTENT MOUNTING
	#vim /etc/fstab
	/dev/sda  /PART1  xfs  defaults  0 0
STEP11:CHECK FOR ERROR
	#mount -a
